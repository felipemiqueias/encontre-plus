# encontre-plus

 1. Sobre o projeto

O Encontre+ é um aplicativo de descoberta de restaurantes desenvolvido com o objetivo de facilitar a busca por estabelecimentos próximos ao usuário de acordo com suas preferências.
A proposta é permitir que o usuário informe o tipo de comida que deseja consumir e selecione um nível mínimo de avaliação. A partir dessas informações, o aplicativo apresenta restaurantes próximos que correspondem aos critérios escolhidos.
O projeto foi desenvolvido como uma solução de Design de Experiência e Prototipação, com foco na criação da interface e na experiência de uso do aplicativo.

 2. Problema

Encontrar um restaurante adequado pode ser uma tarefa demorada, principalmente quando o usuário possui preferências específicas, como determinado tipo de comida, proximidade e uma avaliação mínima.Em muitos casos, o usuário precisa pesquisar diversos estabelecimentos até encontrar uma opção que corresponda ao que deseja.
Diante disso, foi identificado o seguinte problema:
Como facilitar a busca por restaurantes próximos que correspondam ao tipo de comida desejado e ao nível de avaliação esperado pelo usuário?

 3. Solução proposta

A solução proposta é o desenvolvimento do aplicativo Encontre+, uma plataforma de busca e descoberta de restaurantes.
O aplicativo permite que o usuário:
* Informe ou selecione sua localização;
* Escolha o tipo de comida desejado;
* Defina uma avaliação mínima;
* Visualize restaurantes próximos que correspondam aos filtros;
* Consulte informações básicas dos estabelecimentos;
* Visualize a avaliação, distância e tipo de culinária;
* Acesse os detalhes de um restaurante.
Usuário
A solução é destinada a pessoas que desejam encontrar restaurantes de maneira rápida e prática, especialmente usuários que possuem preferência por determinado tipo de comida e desejam considerar a avaliação dos estabelecimentos antes de escolher onde comer.

 4. Telas desenvolvidas
 5. 
Durante o desenvolvimento do projeto foram elaboradas as seguintes telas:
 Tela inicial
Tela responsável por apresentar a proposta do aplicativo e permitir que o usuário inicie sua busca.
 Tela de localização
Permite utilizar a localização do usuário para encontrar restaurantes próximos.
Tela de preferências
Permite selecionar o tipo de comida desejado e definir a avaliação mínima dos restaurantes.
Tela de resultados
Apresenta os restaurantes encontrados de acordo com os critérios selecionados pelo usuário.
As opções apresentam informações como:
* Nome do restaurante;
* Tipo de comida;
* Avaliação;
* Distância;
* Imagem do estabelecimento.
Tela de detalhes
Apresenta informações mais completas sobre o restaurante selecionado, como avaliação, localização, tipo de comida e outras informações relevantes.
